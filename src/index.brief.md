THESIS: A contact-sheet storefront uses real photographs as proof. It keeps one action visible. It refuses the generic brochure made from equal cards.

OWN-WORLD: The visual language uses a quiet surface, dark ink, one accent, decisive display and body type, clear rules, numbered captions, and controlled edges.

STORY: The visitor sees the main offer, place, and action. The visitor then verifies the services, work, credentials, hours, and contact details before booking.

FIRST VIEWPORT: The starter has a ruled header, a large title, one action, a documentary image, and useful shop facts. The agent can change the composition from business evidence. Keep the primary action visible in the first viewport.

FORM: Studio lookbook and contact sheet. It is the sixth ordered direction from concept seed 89a79654.

FINISH: Build the static site and examine mobile and desktop output. Preserve accessibility, reduced motion, and image proportions. Document the result and measured performance. Impeccable is optional during development and is not a production build requirement.
